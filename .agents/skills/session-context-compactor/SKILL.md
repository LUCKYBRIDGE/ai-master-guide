# Skill: Session Context Compactor (session-context-compactor)
> Purpose: Distill ongoing task state, archive completed milestones, and optimize token efficiency for long-running workflows.

## Workflow
1. **Audit Active Context**: Identify completed milestones, discarded hypotheses, and current blocker states.
2. **Archive Decisions & Tasks**:
   - Write key architectural decisions to `docs/decisions/ADR-XXX.md`.
   - Update completed task checklists in `docs/tasks/`.
3. **Produce Compact State Summary**:
   - Current Goal: (1-2 sentences)
   - Completed: (Bulleted list)
   - Next Action: (Single concrete next step)
