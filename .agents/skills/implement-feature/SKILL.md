# Skill: Safe Feature Implementation (implement-feature)
> Purpose: Surgical, incremental code implementation following the Smallest Coherent Change principle.

## Workflow
1. **Prepare Workspace**: Review `AGENTS.md` and relevant architecture docs in `docs/architecture/`.
2. **Incremental Execution**:
   - Implement changes in small, logical chunks.
   - Reuse existing components, hooks, and utilities.
   - Preserve all existing comments and documentation.
3. **Continuous Validation**:
   - Run type checks and build command after each major milestone.
   - Fix any compiler or linter errors immediately.
4. **Update Documentation**: Record any new architectural patterns or components in `docs/`.
