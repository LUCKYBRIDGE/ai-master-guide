# Skill: Feature Planning & Risk Analysis (plan-feature)
> Purpose: Structured pre-planning, risk evaluation, and step-by-step milestone definition before writing code.

## Workflow
1. **Analyze Requirements**: Deeply inspect user request and identify constraints, edge cases, and success metrics.
2. **Explore Codebase**: Locate affected modules, dependencies, data models, and UI components.
3. **Risk Analysis**:
   - Identify potential breaking changes or regression risks.
   - Check performance bottlenecks or bundle size implications.
   - Verify security/secret isolation requirements.
4. **Draft Implementation Plan**:
   - Outline clear, sequential phases (1. Data/Type, 2. Logic/Hook, 3. UI/Component, 4. Verification).
   - Define exact verification criteria and tests.
5. **Document in `docs/plans/`**: Save plan markdown for persistent tracking.
